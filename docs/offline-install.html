نصب آفلاین ADXL345 Toggle

نصب روی Raspberry Pi بدون اینترنت، با PuTTY

پیش‌نیاز روی Pi: Klipper + Moonraker، python3 و sudo (روی MainsailOS به‌صورت پیش‌فرض هست). اینترنت لازم نیست.
  1. 1

    دانلود

    روی کامپیوتر دارای اینترنت

    از صفحه‌ی ریپازیتوری: Code ← Download ZIP

    فایل: ADXL345-klipper-bluepill-main.zip

  2. 2

    انتقال به Pi

    کاربر Pi: biqu — پوشه‌ی home: /home/biqu

    ZIP را در ریشه‌ی فلش بریزید و فلش را به USB خود Pi بزنید. با PuTTY وصل شوید (آی‌پی پرینتر، پورت 22، کاربر biqu):

    lsblk                      # find the USB partition (usually sda1)
sudo mkdir -p /mnt/usb
sudo mount /dev/sda1 /mnt/usb
ls /mnt/usb                # the ZIP should be listed
cp /mnt/usb/ADXL345-klipper-bluepill-main.zip /home/biqu/
sudo umount /mnt/usb       # now you can unplug the drive

    فلش FAT32 یا exFAT باشد؛ NTFS ممکن است mount نشود.

    در Command Prompt ویندوز (همراه PuTTY نصب است). مسیر دارای فاصله باید داخل کوتیشن باشد:

    pscp "C:\Users\hello hamid\Downloads\ADXL345-klipper-bluepill-main.zip" biqu@<PRINTER-IP>:/home/biqu/

    با آی‌پی پرینتر و کاربر biqu وصل شوید و ZIP را با drag & drop داخل /home/biqu بیندازید.

  3. 3

    استخراج

    در ترمینال PuTTY

    cd /home/biqu
unzip ADXL345-klipper-bluepill-main.zip
cd ADXL345-klipper-bluepill-main
# if unzip is missing:
# python3 -m zipfile -e ADXL345-klipper-bluepill-main.zip .
  4. 4

    فلش Blue Pill

    فقط بار اول — سیم‌کشی و menuconfig در docs/bluepill-setup.md

    cd ~/klipper && make clean && make
# flash out/klipper.bin with ST-Link or dfu-util
ls /dev/serial/by-id/   # expect usb-Klipper_stm32f103xb_...
  5. 5

    نصب

    cd /home/biqu/ADXL345-klipper-bluepill-main
bash install.sh --yes

    اگر برد شناسایی نشد یا printer.cfg مسیر دیگری دارد:

    ADXL_MCU_SERIAL=/dev/serial/by-id/usb-Klipper_stm32f103xb_XXXX \
ADXL_PRINTER_CFG=/path/to/printer.cfg \
bash install.sh --yes
  6. 6

    بررسی

    systemctl status adxl-toggle-watcher.service --no-pager
grep -n "include adxl" /home/biqu/printer_data/config/printer.cfg
# both includes must be ABOVE SAVE_CONFIG
  7. 7

    استفاده

    ابتدا سنسور را وصل کنید، سپس در Console:

    ENABLE_ADXL
ACCELEROMETER_QUERY
SHAPER_CALIBRATE
DISABLE_ADXL

حذف

cd /home/biqu/ADXL345-klipper-bluepill-main && bash uninstall.sh
